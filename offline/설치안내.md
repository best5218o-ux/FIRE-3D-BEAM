# 소방활동 정보카드 → 3D 지휘화면 변환프로그램 — 내부 PC 설치 안내

인터넷이 안 되는 내부 PC(행정망, Windows 10/11 64비트)에서 쓰는 설치판입니다.
설치에 인터넷도, 관리자 권한도, 그래픽카드(GPU)도 필요 없습니다(동봉 Python·Tesseract·AI 모델은 CPU 로 동작).
시범운용은 함께 들어 있는 **`시범운용_절차서.md`** 순서대로 진행하세요.

> ## ⚠ 보안 수칙 (반드시 지킬 것)
> - **실제 소방활동 정보카드(PDF)와 변환 결과(3D 화면·활동계획·IFC·검수 파일·학습데이터)는 내부 PC 밖으로 반출 금지.**
>   USB·메일·메신저·인터넷 PC로 옮기지 마세요. 개발자에게 문제를 알릴 때도 **화면 설명이나 가상 건물로 재현**해 주세요.
> - 이 프로그램은 인터넷에 접속하지 않습니다(실행 중 외부 연결을 코드에서 막아 둠). 결과 HTML도 인터넷 없이 열립니다(외부 글꼴·스크립트 없음).
> - 정보카드 ⑧ 관계인 **성명·연락처는 기본으로 결과에서 빠집니다**(역할과 '기재됨'만 표시). 변환할 때마다 결과 파일 전체를 검사해 남은 것이 없는지 창에 표시합니다.
> - 설치 파일은 반입 절차(보안 검사)를 거친 매체로만 옮기세요. 반입 전후로 `FireBIM_offline.zip` 의 SHA256 값을 비교하고, 푼 뒤에는 `SHA256SUMS.txt`로 파일마다 확인할 수 있습니다.

## 0. 필요한 것

| 항목 | 기준 |
|---|---|
| PC | Windows 10/11 64비트, 메모리 8GB 권장(AI 모델 교차검증이 도면당 약 2GB 사용 — 4GB PC 는 `--rules`(규칙만) 권장. 모델 실행이 실패한 도면은 규칙 결과로 자동 계속), 디스크 여유 1.5GB |
| 권한 | 일반 사용자(관리자 권한 불필요) |
| 브라우저 | 크롬 또는 엣지(최신판). 인터넷 익스플로러 불가 |
| 설치판 | `FireBIM_offline.zip` (약 260MB) + `FireBIM_offline.zip.sha256` |
| (선택) IFC 보기 | 기관에서 허가된 IFC 뷰어(예: BIM Vision, FZK Viewer) — 없어도 3D 지휘화면으로 확인 가능 |

## 1. 설치 (처음 한 번, 약 5~10분)

1. zip 의 SHA256 값을 확인합니다(반입 담당자와 함께). PowerShell:
   `Get-FileHash C:\반입\FireBIM_offline.zip -Algorithm SHA256` → 결과가 `FireBIM_offline.zip.sha256` 의 값과 같아야 합니다.
2. zip 을 풀어 나온 `FireBIM_offline` 폴더를 **통째로** `C:\FireBIM` 에 둡니다(`C:\FireBIM\install.bat` 이 보이도록).
   - 한글·띄어쓰기 없는 경로를 권장합니다. `C:\` 에 폴더를 못 만들면 `D:\FireBIM` 이나 문서 폴더 아래 영문 폴더도 됩니다.
   - zip을 풀었는데 파일 이름이 깨지면 **반디집·7-Zip** 으로 다시 푸세요.
3. 폴더 안의 **`install.bat`** 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.
   - [1/4] Python → [2/4] 라이브러리(오프라인) → [3/4] Tesseract → [4/4] **자체시험**(가상 표준양식 정보카드 1동 변환 + AI 교차검증 + 검수 반영, 2~5분)
   - 마지막에 `■ 자체시험: 정상 (10/10)` 처럼 나오면 설치 끝입니다.
4. 설치가 끝나면 폴더 구성은 이렇습니다.

| 폴더·파일 | 내용 |
|---|---|
| `변환.bat` | 정보카드 PDF(+따로 받은 평면도) → 3D 지휘화면·사전 활동계획·검수화면·IFC |
| `검수.bat` | 검수 결과를 반영해 3D·IFC·활동계획 다시 만들기 + 학습데이터 쌓기 |
| `자체시험.bat` | 설치 상태·전 기능 시험(가상 건물) — 언제든 다시 실행 가능 |
| `채점.bat` | 가상 건물 18동 인식 성능 채점 화면 |
| `python\`, `tesseract\`, `wheelhouse\`, `app\` | 프로그램 부품(지우지 마세요). AI 모델은 `app\models\` |
| `MANIFEST.txt`, `SHA256SUMS.txt` | 구성 목록·파일별 무결성 값 |
| `결과\`, `학습데이터\`, `logs\` | 사용하면서 생기는 폴더(반출 금지) |

## 2. 변환하기

1. 정보카드 PDF 파일을 **`변환.bat` 아이콘 위에 끌어다 놓습니다**(여러 개·폴더째 가능).
   - 정보카드에 평면도·진압작전도가 없거나 일부 층만 있으면, **따로 가진 도면 파일을 카드와 함께 끌어다 놓으세요**.
     파일 이름에 층을 넣습니다: `지상1층.png`, `B1.pdf`, `지하2층.jpg`, `2F~9F 기준층.png`, `옥탑.png`, `진압작전도.jpg`.
     카드에 이미 있는 층은 카드 쪽을 씁니다. 여러 카드를 한꺼번에 놓을 때는 카드와 그 도면을 같은 폴더에 두세요.
   - 정보카드가 한글(hwp)·Word(docx) 파일이면 한글·Word 에서 **「PDF로 저장」** 한 뒤 넣으세요(LibreOffice 가 설치된 PC 에서만 자동 변환).
2. 검은 창에 진행 상황이 나오고, 끝나면 3D 지휘화면·활동계획·결과 폴더가 자동으로 열립니다.
   글자 인식·AI 모델 교차검증 때문에 도면 1장당 30초~1분 걸립니다(도면이 많으면 수 분). 규칙만 쓰려면 명령창에서 `변환.bat 카드.pdf --rules`.
3. 결과는 **PDF와 같은 폴더의 `<이름>_변환결과`** 에 생깁니다(그 폴더에 쓸 수 없으면 `C:\FireBIM\결과\`).

| 결과 파일 | 쓰임 |
|---|---|
| `<이름>_3D지휘화면.html` | 3D 지휘화면(크롬·엣지). 층 전환, 진입로·대피로, 소방시설(분류·위치 확실성), 화점 지정 → 경로·호스·공기호흡기·인명검색 |
| `<이름>_활동계획.html` | 사전 활동계획(인쇄용): 위험요소, 면별 소방차 접근·펌프차·송수구·소화전·고가사다리차·진입창, 진입로, 수직동선, 층별 대피·소방시설, 확인사항 |
| `<이름>_검수화면.html` | 자동 인식 검수 화면(틀렸을 법한 곳부터) |
| `<이름>.ifc` | BIM(IFC4) 파일 |
| `<이름>_결과.json` | 변환 결과 원본(검수 반영에 필요 — 지우지 마세요) |
| `<이름>_입력합본.pdf` | (따로 도면을 붙였을 때만) 카드+도면 합본 — 원본과 같이 취급(반출 금지) |

창 끝에 `개인정보 검사: 관계인 성명·연락처 N건 모두 결과에 없음` 이 나오는지 확인하세요. `✗` 가 나오면 결과를 쓰지 말고 담당자에게 알리세요.

## 3. 검수하기 (틀렸을 법한 곳만 확인)

1. `<이름>_검수화면.html` 을 엽니다(크롬·엣지).
2. 오른쪽 **「검수 필요」** 목록이 오류 가능성 높은 순으로 나옵니다. 위에서부터 **맞음 / 틀림** 을 누르세요.
   - 도면 위 **노란 점선** = 확인이 필요한 기호. 목록을 누르면 그 자리로 확대됩니다.
   - **벽·문 교차검증(규칙 ↔ AI 모델)** 항목: 「모델이 맞음」`Y` · 「규칙이 맞음」`N` · 「나중에」`L`
   - 빠진 기호: `A` 키 → 숫자 `1`~`5`(비상구·소화전·수신기·가스밸브·승강기) → 도면 클릭
   - 빠진 계단·승강기: `S` → 도면에 상자를 끌어 그리고 종류·연결층 선택
   - 잘못된 기호·문·벽: 클릭 → `Delete`, 위치는 끌어서 옮김, 종류는 숫자 키
   - 문 추가 `D`, 벽 추가 `W`, 되돌리기 `Ctrl+Z`, 도움말 `?`
   - 층정합: 「아래층 벽 겹쳐보기」(`G`)로 분홍 선이 도면 벽과 맞는지 보고 **정상 `O` / 불량 `X`**. 어긋나면 `Ctrl+화살표`로 0.1m씩 맞춥니다.
   - 한 층을 다 보면 **`Enter`(이 층 검수 완료)** — 완료한 층만 학습데이터로 쓰입니다.
3. 오른쪽 위 **「검수 결과 저장」**(`Ctrl+S`) → `다운로드` 폴더에 `<이름>_corrections.json` 이 저장됩니다.
   (작업 중 내용은 브라우저에도 자동 저장되어, 창을 닫았다 열어도 이어서 할 수 있습니다.)
4. 그 파일을 **`검수.bat` 위에 끌어다 놓으면**
   - 결과 폴더에 `<이름>_검수반영.html`(3D)·`<이름>_검수반영.ifc`·`<이름>_검수반영_활동계획.html` 이 새로 만들어지고
   - `C:\FireBIM\학습데이터\` 에 학습용 라벨(COCO 형식)이 쌓이며
   - `C:\FireBIM\채점현황.html` 의 「검수 기반 성능」이 갱신됩니다.
   - 다운로드 폴더의 `*_corrections.json` 은 반영 뒤 결과 폴더에 `_검수기록.json` 으로 복사되므로 다운로드 폴더 쪽은 지워도 됩니다.

## 4. 자체시험·채점

- `자체시험.bat`: 가상 표준양식 정보카드(가상 건물, 진압작전도 포함)로 변환 → 표준양식 해석·진압작전도 인식·소방시설·대피로·AI 교차검증·
  개인정보 제외·오프라인(외부 자원 없음)·IFC 열기·검수 반영까지 10개 항목을 확인합니다. 결과는 `결과\_자체시험\`(가상 자료).
  빠른 확인만: 명령창에서 `자체시험.bat --quick`(설치 확인만).
- `채점.bat`: 동봉된 가상 건물 18동을 자동 변환·채점(5~15분)하고 `채점현황.html` 을 엽니다.
  실제 건물 성능은 검수 결과가 쌓일수록 「검수 기반 성능」 표에 나타납니다.

## 5. 문제 해결

| 증상 | 해결 |
|---|---|
| `install.bat` 에서 "wheelhouse 폴더가 없습니다" | 폴더를 통째로 복사했는지 확인 |
| "OpenCV 불러오기 실패 … DLL" | Windows **N/KN 에디션**이면 「미디어 기능 팩」 설치(전산 담당에게 요청) |
| "IfcOpenShell/PyMuPDF/onnxruntime … DLL" | `install.bat` 재실행(동봉 VC++ 런타임 설치). 그래도 안 되면 전산 담당에게 「Visual C++ 2015-2022 재배포 패키지 x64」 설치 요청 |
| "AI 모델 교차검증 생략" / "도면 N AI 모델 교차검증 실패" | 메모리 부족 또는 onnxruntime 문제 — 결과는 규칙만으로 정상 생성됨. 다른 프로그램을 닫고 다시, 계속되면 `--rules` 로 사용 |
| "대피로 계산 생략" | `install.bat` 재실행(scikit-image 설치 확인) |
| "Tesseract 없음" / "한국어 언어팩 없음" | 아래 「Tesseract 직접 설치」 |
| "층을 알 수 없음: 파일이름" | 따로 넣은 도면 파일 이름에 층을 넣기(예: `지상3층.png`) |
| 한글 폴더에서 오류 | 설치 폴더를 `C:\FireBIM` 으로 옮겨 다시 실행 |
| 파일 이름에 `&` 가 있으면 끌어놓기 실패 | 파일 이름에서 `&` 를 빼고 다시 |
| 3D 화면이 안 보임 | 크롬·엣지 최신판 사용. 그래픽 가속이 꺼진 PC 는 느릴 수 있음(동작은 함) |
| 백신이 `python.exe`·`tesseract.exe` 를 막음 | 전산 담당에게 `C:\FireBIM` 예외 등록 요청(설치판 SHA256 값 제시) |
| 그 밖의 오류 | `C:\FireBIM\logs\` 의 최근 파일 내용을 담당자에게 **말로** 전달(파일 반출 금지). 로그에는 오류 위치만 있고 카드 내용·입력 파일 이름은 가려져 있음 |

### Tesseract 직접 설치 (동봉판이 없을 때)
- 설치파일: UB Mannheim 빌드 `tesseract-ocr-w64-setup-5.4.0.20240606.exe`
  - 인터넷 PC에서: https://github.com/UB-Mannheim/tesseract/wiki (→ releases) 또는 https://digi.bib.uni-mannheim.de/tesseract/
  - `installers\` 폴더를 만들어 넣고 `install.bat` 다시 실행(관리자 권한 창이 뜰 수 있음) — 또는 기본 위치 `C:\Program Files\Tesseract-OCR` 에 설치해도 자동으로 찾습니다.
- 한국어 언어팩: `kor.traineddata`(tessdata_fast) — https://github.com/tesseract-ocr/tessdata_fast 의 `kor.traineddata`, `eng.traineddata` 를 `tesseract\tessdata\` 에 복사.

### Python 을 따로 설치해야 할 때 (동봉 `python\` 이 막힌 경우)
- python.org 의 **Python 3.11.9 64-bit** 설치파일(`python-3.11.9-amd64.exe`)로 "Install for current user"(관리자 불필요) 설치 → `python\` 폴더를 지우거나 이름을 바꾼 뒤 `install.bat` 실행(자동으로 `venv\` 생성).
- 동봉판 출처: https://www.python.org/ftp/python/3.11.9/python-3.11.9-embed-amd64.zip

### 설정(환경변수, 고급)
| 변수 | 뜻 |
|---|---|
| `FIREBIM_INCLUDE_CONTACTS=1` | 관계인 성명·연락처를 지휘화면·IFC 에 포함(현장 연락이 꼭 필요할 때만, 결과 취급 주의) |
| `FIREBIM_MODEL=0` | AI 모델 교차검증 끄기(규칙만, 더 빠름) |
| `FIREBIM_DONG=2` | 여러 동 정보카드에서 2번째 동 변환 |
| `FIREBIM_EVAC=0` | 대피로·진입로 계산 끄기 |

## (개발자용) 설치판 만들기 — 인터넷 되는 PC에서

```bash
bash offline/build_bundle.sh                # → offline/build/FireBIM_offline/ + FireBIM_offline.zip + .zip.sha256
LINUX_TEST=1 bash offline/build_bundle.sh   # + 같은 버전 리눅스 휠로 오프라인 설치 → launch.py selftest(변환·AI 교차검증·검수 반영) 재현
```
- 필요한 것: python3(3.11), pip, curl, 7z, pefile(선택), viewer/node_modules(esbuild) — 7z가 있으면 Tesseract 설치파일을 풀어 **관리자 권한 없이 쓰는 휴대용** `tesseract\` 를 만듭니다.
- 3D 뷰어 번들(`viewer/dist/app.js`)을 먼저 만들어 동봉합니다(내부 PC에는 node 불필요).

  ① `pip install --dry-run --no-index` 로 **인터넷 없이 전부 풀리는지**, ② `bundle_tools.py imports` 로 **실행 코드의 모든 import 가 휠에 있는지** 확인합니다.
- `app\` 에는 실행에 필요한 것만(firebim·review·채점용 evalr 일부·models(str_seg GPU 모델 + spa_seg)·templates·samples·viewer 번들) 넣고,
  synth/·strseg/·torch·AI허브 자료·실제 카드·spec/ 이 섞이면 빌드가 멈춥니다.
- 큰 파일(wheelhouse·python·tesseract·zip)은 `offline/build/` 에만 생기며 코드 저장소에 넣지 않습니다.
