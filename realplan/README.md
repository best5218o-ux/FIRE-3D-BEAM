# 실제 도면 전처리(realplan) — 방법과 지표

가상 도면(회색 띠 벽·그리드·초록 기호)에만 맞춰진 기존 엔진(geom/vision)과 **독립된** 모듈.
AI허브 「건축 도면 데이터」 원천 PNG(A3@300dpi 흑백, 4963×3509)로 시험. 벽 라벨(STR) 없음 → 치수 자기지도 지표.
※ AI허브 원천 이미지·겹침 그림(out_real/overlays)은 로컬 시험용 — 외부 공개·재배포 금지.

## 사용
```
python -m fire3dbeam.realplan 도면.png 출력폴더                      # 시트 1장: 배치·영역별 겹침 그림 + 요약
python -m evalr.realplan_eval ./aihub/obj2 --split dev   # 개발 세트(파일명 정렬, 5번째마다 제외) → out_real/summary_dev.json
python -m evalr.realplan_eval ./aihub/obj2 --split hold  # 보류 세트(5번째마다) — 임계값 조정에 쓰지 않음
  옵션: --limit N(무작위 표본) --overlays N(겹침 그림 시트 수) --workers 2 --files a.png b.png
```
출력: `out_real/summary_<split>.json`(+ 마지막 실행 = `summary.json`), `results_<split>.jsonl`(시트·영역별), `overlays/*_sheet.png`, `*_rK.png`.
수동 판정: `evalr/realplan_manual.json` — 있으면 summary 의 `manual` 에 자동 지표와의 일치율 기록.

## 방법 (fire3dbeam/realplan.py)
해상도: 원본 F(300dpi) / 해석 H=1/2(150dpi, **최소값 풀링** — 가는 선이 흐려지지 않음) / 배치 Q=1/4.
1. **시트 배치** `sheet_layout`: 시트 길이 33% 이상 가는 직선 중 '평행 짝'이 없거나 가장자리에 있는 선 = 도곽·구획·그리드선 → 제거.
   긴 수평·수직선 밀집 = 도면 코어 → 떨어져 그린 치수 띠(가늘고 긴 코어)는 옆 큰 코어에 병합 → 약 30mm 안 잉크 덩어리(치수·그리드 번호) 흡수.
   벽이 없는/작은 영역(표제란·범례·주기)은 `kind=other`. 영역 아래·위 가로 글자 덩어리를 OCR(kor+eng)해 '평면·세대·PLAN·㎡·형·층'이 있으면 캡션.
2. **축척 먼저** `dims_one`/`consensus`: 가는 긴 선(치수선, 점·원 눈금 끊김은 닫기로 이음) 위 글자 띠만 남긴 이미지에서 글자 크기 덩어리만 이진화
   (작은 글자는 2배 확대) → Tesseract(숫자·쉼표) → `12,500`/`4530` 해석 → 숫자 아래 치수선의 눈금(연장선·사선·점, 글자 칸 제외) 사이 구간 px ÷ mm.
   세로 치수는 영역을 90° 돌려 같은 방식. 후보 px/mm 중 ±3% 안에 가장 많이(구간 길이 가중) 모이는 값 = 축척, 신뢰도 = 합의비율×min(1, 합의수/5).
3. **벽 표현 분류** `wall_style`: 검정 채움(filled) / 회색 채움(filled_gray) / 해치(hatched: ±45° 짧은 선) / 겹선(double: 평행선 간격 히스토그램 봉우리) / 단선(single).
4. **벽 추출** `wall_mask`: 축척이 있으면 벽 두께 90~480mm 를 px 로 바꿔 사용(없으면 간격 히스토그램).
   겹선·해치: 긴 가로(세로)선 → 두께 방향 닫기(dmax) → 열기(dmin, 한 줄짜리 선 제거) → 길이 방향 열기. 채움: 굵기 열기 + 방 크기 덩어리(바닥 무늬) 제외.
   숫자가 붙은 **바깥 치수선**(선 너머 벽 질량 <3%)은 지우고, 각 변의 가장 안쪽 바깥 치수선 밖은 건물이 아님(범례·상세도·연장선 제거).
5. **외곽** `outline`: 벽 마스크를 1.3m(축척 기준) 닫기 → 바깥과 연결 안 된 곳 채움 → 0.9m 열기(튀어나온 선 제거) → 가장 큰 덩어리 + 20% 이상 덩어리(테라스로 떨어진 동).
   벽 선분 `wall_segments`(축정렬, H px).

## 지표 (summary.json)
- `crash_rate`, `runtime_mean_s/p90`, `images_with_plan`, `plans_per_image`, `style_dist`, `scale_1_to_hist`(300dpi 기준 1/N)
- `outline_found`, `scale_found`, `scale_conf_ge_0.5` (도면 영역 기준 %)
- **`err_union`(주지표)**: 축(가로/세로)별로 합의에 든 치수들의 합집합 범위(=최외곽 눈금 사이, mm) ↔ 외곽 범위(mm).
  검사 조건: 끊김 없는 사슬(합집합 95% 이상)이 그 치수선의 첫~끝 눈금을 90% 이상 덮을 때만(일부만 읽힌 사슬로 외곽을 탓하지 않게).
  오차 = min(|외곽−치수|, |외곽−2t−치수|)/치수 (치수가 외벽면 기준 또는 벽 중심 기준일 수 있어 벽 두께 t 만큼 허용). `err_raw` 는 보정 없음.
  `edge_mm` = 양 끝 외곽−치수 차(mm): 한쪽만 크면 돌출부(실외기·발코니)가 치수에 없거나 외곽이 번진 것.
- `err_total`: 가장 긴 단일 치수(전체치수, 외곽 폭 60% 이상) ↔ 외곽 — 과제 원안 정의. 벽 중심 기준 전체치수는 돌출부를 빼므로 err_union 보다 큼.
- `by_type`(APT/DEH/ROW), `by_style`
- 한계: 축척은 같은 치수에서 구하므로 '외곽 추출 + 치수 해석 일관성'을 재는 지표이지 절대 정답은 아님. 치수 없는 분양용 평면(APT 일부)·회전 도면은 검사 불가.

## 아직 안 되는 것
- **검정 채움 분양 평면(APT 일부·DEH)**: 벽은 잘 잡지만 발코니 창(가는 선)이 벽이 아니라 외곽이 닫히지 않아 일부만 → 창 선을 외곽 닫기에만 더하는 처리 필요. 굵은 무콤마 숫자·선 아래 숫자는 이번에 지원했으나 축척 30%.
- **겹선 실시설계도(APT 단위세대·ROW)**: 치수 사슬이 촘촘하면 두 치수선이 겹선 벽처럼 보여 외곽이 치수 띠까지 번짐(바깥 치수선 제거가 일부만 작동), 가구·설비·해치 바닥이 벽으로. 1/40·1/80 병기 도면은 축척 오합의.
- **해치 벽**·곡선/사선 벽(DEH), **회전된 평면**(ROW 일부): 축정렬 전제라 실패. 치수 없는 도면(영문 PLAN, 분양 평면 일부)은 검사 불가.
- 지표 한계: 치수 사슬이 돌출부(실외기실·발코니)를 안 덮으면 외곽이 맞아도 오차로 잡힘(수동 '외곽 양호'인데 err .22~.33 사례). 조각난 외곽도 범위만 맞으면 통과.

## STR(벽 라벨)이 있으면
벽 마스크 픽셀 IoU·벽 선분 재현율/정밀도를 직접 잴 수 있어(지금은 외곽 범위만 간접 측정), 표현별 임계값(두께 범위·해치 판정·바닥 채움 제외)을 라벨로 맞추고,
치수 띠·가구·해치 바닥 오검출을 정량화하며, 분양 평면처럼 치수 없는 도면도 평가 가능. 학습형 벽 분할(U-Net 등)의 학습·검증 데이터로도 사용.

## 축척·외곽 개선 + 외곽 직접 채점 (2026-09-30 오후) — 실제 도면 기본 경로 = 분할 모델
기본값 변경: `process_sheet/analyze/process_gray(model=None)` → 모델 파일(models/str_seg.onnx)+onnxruntime 이 있으면 **모델 벽 경로가 기본**, CLI `--rules`/`model=False` = 규칙 벽.
`evalr.realplan_eval` 도 기본 모델(`--rules` 로 규칙). 가상 정보카드 파이프라인(geom/vision/pipeline)은 realplan 을 쓰지 않으므로 영향 없음.
※ 아래 축척 변경 중 시트 공통 축척·숫자 붙이기·180° 재판독은 규칙 경로에도 적용 → 이전 "규칙 경로 출력 바이트 동일"은 더는 성립 안 함(환경변수로 끄면 이전과 같음).

축척(치수) — 끄는 환경변수는 괄호:
- **시트 공통 축척** `sheet_scale` (`REALPLAN_SHEET_POOL=0`): 한 시트 여러 평면의 치수 후보를 모아 합의 → 자체 합의가 없거나 신뢰도<0.5 인 영역은
  그 영역 숫자 중 공통값에 맞는 수가 자체 합의 수 이상일 때 공통값 채택(`scale_src='sheet'`, 1/50 상세처럼 다른 축척은 유지). `consensus(force=)` 로 그 값의 inlier 재표시.
- **문 폭 사전값**(모델 경로, `REALPLAN_DOOR_PRIOR=0`): 모델 문 개체 폭 중앙값 ≈ 1040 mm(obj2 개발 60장 중 신뢰 축척 영역 44개에서 맞춤, 10~90% ±11%)
  → (a) 합의 후보가 문 축척과 1.45배 넘게 어긋나면 점수 ×0.25, (b) 치수를 전혀 못 읽은 영역은 문 축척(`scale_src='doors'`, 신뢰도 0.2).
- OCR: 둘로 끊긴 숫자('12,' + '500') 붙이기(`REALPLAN_MERGE_WORDS=0`), 세로 치수 글자가 위→아래로 쓰인 도면은 돌린 띠를 180° 뒤집어 한 번 더 읽기(`REALPLAN_FLIP_VERT=0`, 읽힌 숫자가 적을 때만).
외곽(모델 경로):
- 닫기 후보 0.3/0.6/1.3 m 중 채움 면적이 1.3 m 닫기의 85% 이상인 **가장 작은 닫기**(`REALPLAN_M_CLOSE`, `REALPLAN_FILL_KEEP`) — 테라스·오목부를 덜 메우고, 벽 틈이 새면 큰 닫기로.
- 모델 벽은 이어진 덩어리라 선분 수가 적음 → 평면 판정 선분 하한 8 → 4(작은 단순 평면 누락 방지).
- 축척이 없으면 닫기가 도면 크기 비례값이라 방마다 따로 채워지던 도면(흐린 해치 외벽)이 문 폭 축척으로 해결되는 경우가 많음.

외곽 직접 채점 `evalr/footprint_eval.py` (STR 라벨 = 정답): 라벨 벽∪창∪문을 원본 1/4(75dpi)로 그려 ≈1.3 m 팽창으로 묶은 덩어리(라벨된 평면)마다
작은 닫기(0.1~0.85 m 중 채움 안정값) 후 채움 = 정답 외곽. 예측 = `process_gray`('plan' 영역 외곽). STR 영상은 긴 변 2048(≈124dpi) → 원본 크기로 되돌려 넣고,
모델에는 축소본을 그대로 `src_dpi=300·f` 로(`model_src`). 덩어리마다 겹치는 예측 성분 전체(번진 부분 포함) − 다른 라벨 평면 → IoU·재현·정밀.
가장 큰 덩어리의 10% 미만 조각(실외기 선반·벽 토막 라벨)은 제외. `clean` = 라벨 벽 화소가 잉크 위에 있는 비율 ≥0.6(라벨 위치 어긋남 제외).
`python -m evalr.footprint_eval run --split dev|held --limit N [--rules] [--nodims] [--overlays K] --tag T` (분할 = strseg.data.split_of, dev=train+val, 순서 = 파일명 해시 고정). 모델 라벨 캐시 `FP_MODEL_CACHE=폴더`.

→ 외곽 IoU 는 **거의 그대로**(정밀↑·재현↓ 맞바꿈). 조각난 외곽(흐린 해치 외벽 .42→.92)·테라스 메움은 좋아졌지만, 작은 닫기가 벽 틈 있는 방을 빼거나(.99→.79),
124dpi 영상에서 문 폭 축척이 틀린 도면(.69→.37)이 나빠짐. 닫기 선택 비율 0.95 도 개발 .907 로 차이 없음. 반복 조정은 개발 뒤쪽 표본(offset 100~130, 치수 없이)에서만.
남은 약점: 124dpi(STR) 영상은 치수 OCR 이 거의 안 됨(되돌려 키운 흐린 글자) → 원본 300dpi 필요, 회전 평면(ROW 30°)은 치수·문 모두 못 읽어 축척 없음,
테라스·데크·실외기실(난간·가는 선)의 포함 여부가 라벨과 어긋남, 라벨 일부만 된 평면·라벨 위치 어긋남(정답 잡음), 1/50 상세+1/100 평면 혼재 시트의 축척 오합의.

## 새 기본 모델 재측정 + 외곽 개선 (2026-10-02)
STR GPU 모델(기본)로 같은 표본을 다시 잼. 치수 자기지도 지표(obj2)는 거의 그대로(개발 err_union ≤5% 62.7→63.5%, 보류 78.3→81.4%), STR 외곽 IoU 는 아래 두 수정으로 개선:
- `outline` 채움 버그 수정(`REALPLAN_FILL_FIX`, 기본 켬 — 규칙 경로도): 닫힌 벽 마스크가 영역 가장자리에 닿으면 벽 화소(연결 성분 0)까지 바깥으로 쳐서 방 구멍만 채우던 것.
- 모델 경로 바깥 치수선 자르기 국소화(`REALPLAN_M_DIMCLIP=local` 기본, 예전 `global`): 바깥 치수선이 벽 범위의 60% 미만을 덮으면 그 선 구간(+10%)에서만 선 너머를 지움
  (한 영역에 크기가 다른 평면이 나란히 있을 때 옆 평면 벽이 잘리던 것).
STR 외곽 IoU 평균: 개발 60장 .913 → .946(≥0.9 79.5→87.9%), 보류 80장(1회) .882 → .910(≥0.9 70.6→74.8%, ≥0.8 82.8→87.7%). obj2 치수 지표는 변화 없음 수준.
평가 속도용: `REALPLAN_MODEL_CACHE=폴더` 면 realplan_eval 이 모델 라벨을 캐시(모델 파일 이름별).
